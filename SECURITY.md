# Security Policy

This is an unofficial community source-patch repository.

No formal security audit has been performed for the patch or the optional
prebuilt binary release asset.

Do not report private RustDesk Server keys, API tokens, deployment logs, or
hostnames in public issues.

For security-sensitive reports, publish only a minimized reproduction using
non-secret test data. If a report requires real deployment material, sanitize it
first.

This repository does not provide official RustDesk Server support.

Release binaries must be treated as community builds. Verify checksums, inspect
the matching source archive, and use your own RustDesk server keys and
configuration.
