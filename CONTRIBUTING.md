# Contributing

Contributions should keep this project narrow:

- source patches only;
- no compiled binaries;
- no private deployment files;
- no RustDesk keys;
- no `hbbr` changes unless a separate issue justifies them;
- no claims of official RustDesk affiliation.

Before proposing a change:

1. Check current upstream RustDesk Server.
2. Prefer an official upstream release if it already contains the behavior.
3. Keep patches small and reviewable.
4. Update `SOURCE_MANIFEST.md` when patch provenance changes.
5. Update build and test documentation when commands change.

Patch submissions should include a summary of changed files and functions.
